# Support

Use GitHub Issues for reproducible defects, documentation errors, feature requests, and mathematical questions about the implemented representations.

Before opening an issue:

1. Confirm that you are using the latest release.
2. Run `python -m pytest -q` from the repository root.
3. Record `python --version`, `python -m pip freeze`, and the operating system.
4. Reduce the input to the smallest file that still reproduces the problem when possible.
5. Remove confidential or proprietary image content.

General installation and usage instructions are in `README.md`. Mathematical derivations are in `docs/MATHEMATICS.md`, and document-export requirements are in `docs/WORD_PDF_EQUATION_EXPORT.md`.
